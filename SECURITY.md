# Política de segurança

## Relatando uma vulnerabilidade

Não abra uma issue pública para falhas que possam expor dados, credenciais ou a máquina do usuário.

Use o recurso **Private vulnerability reporting** na aba **Security** do repositório. Inclua uma descrição do impacto, passos mínimos para reprodução e, quando possível, uma sugestão de correção.

Evite anexar tokens, chaves, arquivos de sessão ou conteúdo de conversas. Substitua qualquer valor sensível por exemplos fictícios.

## Escopo de privacidade

O Agent Meter processa dados localmente. O aplicativo não deve enviar prompts, chaves, conteúdo de conversas ou telemetria para serviços externos. Mudanças que alterem essa garantia precisam ser documentadas e revisadas explicitamente.
